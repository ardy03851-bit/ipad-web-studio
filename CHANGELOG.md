# Changelog

## 1.0.0 — 2026-10-26

Initial release.

- Single-file IDE: CodeMirror 5 editor, Emmet, tabs, file tree, touch toolbar, long-press context menu, command palette, snippets, minimap and soft wrap
- Live preview with CSS hot-swap, console panel, viewport simulator, pause, refresh and Launch
- Visual site builder with select, move, resize, rotate, multi-select, snapping, guides, align and distribute, element tree, inspector, insert palette and source write-back
- Design Mode theme designer with Midnight, Slate, Nord, Paper and Solarized presets
- Autosave, 60-snapshot version history with diffs, ZIP import and export, Web Share
- Landing, Portfolio, Blog post and Coming soon templates
- Installable PWA with offline service worker
